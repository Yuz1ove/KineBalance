# 正式量測可見計數與 production 發布

本輪依使用者最新指令取代「正式計數收在詳細資訊」的呈現方式。V1.2.1 核心、手部模型、品質判定、尺度處理、40 ms 短促候選防護及原資料均不變。

`MeasurePage` 在影像下方固定顯示「本次有效開合」、「剩餘時間」及追蹤狀態。數字直接取 `RealtimeKinematics.tapCount`，沒有第二套事件偵測／UI 累加器、插值、預估或聲音。頻率及幅度仍位於收合的詳細資訊。影像高度依 viewport 縮放，正式開始會自動將影像與數字一起帶到可見位置；整組在量測區內 sticky，窄高螢幕用上下配置、低矮螢幕用左右配置。

預覽與倒數不顯示正式計數；倒數結束歸零並建立正式輪次。失追保留核心已完成事件數，提示「暫停辨識」，時間不暫停／延長。完成時凍結最後一次正式回報的計數，再以同一批正式 frames 和同一核心產生最終分析。本核心沒有額外的完成後品質篩選；若 UI 最後值與最終／保存結果不同，頁面顯示兩個值並說明差異尚未釐清，不靜默改寫凍結值。重新量測清除凍結值。

回歸涵蓋正式起點 0、逐 prefix 的原核心完成事件對應畫面一次增量、同值重複回報不增加、失追保留、倒數實際變化、完成後舊 callback 不再更新、重測歸零及故意製造差異時的明示提示。原小幅／快速小幅／衰減的 expected 不變。虛擬鏡頭腳本另驗桌面及手機 viewport 的影像／數字／秒數邊界，面板維持收合；回放不能代替真人逐次核對。

使用者本輪明確授權 commit、push、Vercel production 與正式網域切換。先用 production target / skip-domain 建立候選並驗證，再 promote 原 project，最後從正式網址核對 build identity 與保存讀回。環境僅公開 API base，後端依精確 origin 接線；不搬資料、不更動其他 project。最終部署與驗收收據位於 workspace `output/live-counter-production-20260928`。
